## Critérios de uma boa pauta eleitoral
1. **Relevância** — conversa com o momento (briefing) ou é perene útil.
2. **Ângulo claro** — qual é a SUA entrada? (análise, comparação, mito vs. fato, explicador)
3. **Formato certo** — reativo/emocional → Reel; explicativo/em etapas → carrossel.
4. **Checável** — dá para sustentar com fonte? Se não, não entra.
5. **Diferenciação** — foge do "todo mundo já falou"?
