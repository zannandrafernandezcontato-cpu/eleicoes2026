# 02 — Roteiros

Onde a pauta aprovada vira roteiro pronto para gravar/montar.

- **`templates/template-reel.md`** — estrutura de Reel/TikTok/Short (gancho → contexto → desenvolvimento → CTA).
- **`templates/template-carrossel.md`** — estrutura de carrossel card a card.

## Convenção de nomes
Salve cada roteiro como:
```
02-roteiros/AAAA-MM-DD_formato_tema-curto.md
```
Ex.: `2026-10-08_reel_lider-1o-turno-sempre-vence.md`

## Como pedir
*"Faz o roteiro do Reel da pauta 2"* ou *"transforma a pauta 1 em carrossel de 8 cards"*.
Eu uso o template, preencho com base na pesquisa, cito as fontes e já entrego o pacote de publicação (legenda + hashtags).
